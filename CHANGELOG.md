# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Unreleased]

### Added
- `services/care_monitor` — аддон Care Monitor: события Frigate → кадры →
  цепочка вопросов к vision-модели (упал, спит, поза, еда, туалет, походка)
  → база и уведомления. Срок хранения данных, промпты, скрипты теста промптов
  (`eval/`), разбор точности (`RECOMMENDATIONS.md`)
- `services/care_api` — аддон Care Journal API: лента журнала для сайта,
  оценка верно/ложно, переоценка; демо-журнал на английском (`/demo/`)
- `services/care_demo` — сборщик демо-базы из отобранных событий и страница
  мониторинга данных
- Первая публикация репозитория: конфигурация Frigate, автоматизации Home
  Assistant, сборка модели YOLOv9, скрипты vision-LLM, ops-обвязка
- Документация на русском (10 разделов), обзорные разделы на английском и иврите
- ADR: решения и отменённые направления — GPEN/GFPGAN, Twilio, выбор
  медицинских устройств

### Known issues
- Frigate отдаёт 502 на auth-сервисе после включения секции `classification`
- Распознавание лиц путает членов семьи; требуется чистка обучающей базы
- Голосовое оповещение через Яндекс.Станцию заблокировано на авторизации
- Хост изредка полностью выключается (баг ASUS BIOS/EC + ядро Linux)
