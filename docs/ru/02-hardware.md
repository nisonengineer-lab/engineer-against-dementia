### Почему ноутбук — плохой хост

Изредка **полностью выключается** — не уходит в сон, а именно power off.
Баг задокументирован на Launchpad, причина не установлена, похоже на
связку ASUS BIOS/EC + ядро Linux. Программно не лечится.

Для системы, которая должна разбудить ночью, «изредка выключается» —
дисквалифицирующая характеристика. Отсюда переезд на Pi 5.

### Почему EZVIZ — плохие камеры

Не «дешёвые, но терпимо», а конкретные отказы:

- слабый substream, для детекции годится плохо;
- **Local RTSP самопроизвольно отключается** в настройках — камера
  просто перестаёт отдавать поток, пока не зайдёшь и не включишь заново;
- IP «уезжает» по DHCP, конфиг ломается;
- Wi-Fi вместо PoE: лишняя точка отказа и лишний провод питания.

Пароль RTSP у EZVIZ — это **код верификации с наклейки на корпусе**, а не
пароль от аккаунта. Меняется только сбросом камеры к заводским.

## Решённые вопросы по железу

Проверено, чтобы не выяснять заново:

**AI HAT+ работает только с Raspberry Pi 5.**
Нужен PCIe. Не Pi 2/3/4. Не Orange Pi (кроме отдельного «голого»
M.2-модуля Hailo — это не официальный HAT).

**Один Pi 5 = один AI HAT.**
Физически один PCIe-слот. Второй Hailo на ту же плату не поставить.

**13 TOPS (Hailo-8L) хватает** на 3–5 камер с детекцией и распознаванием
лиц. 26 TOPS берётся под запас: больше камер или несколько моделей
одновременно.

**GPU для тяжёлых моделей остаётся на большом ПК.**
Гибридная архитектура не от бедности, а по расчёту: LLM на Pi не влезет
ни по памяти, ни по скорости, а детекции ускоритель на Pi достаточен.

## Медицинские устройства — итог исследования

Ничего не куплено. Выводы, чтобы не искать повторно:

### Рекомендовано

**Withings ScanWatch 2 + BPM Connect** — лучший вариант по совокупности:

- официальная интеграция с Home Assistant;
- **настоящая манжета** для давления (BPM Connect), одобренная FDA, а не оптическая оценка по запястью;
- разовая покупка, без подписки.

### Отклонено и почему

| Устройство | Причина отказа |
|---|---|
| Omron HeartGuide | снят с производства |
| Samsung Galaxy Watch | не даёт настоящего измерения давления — производитель признаёт это сам |
| Hilo Band / Aktiia | дорогая **обязательная** подписка + возрастное противопоказание >85 лет. Деду 85 — это блокирующий фактор, а не мелочь |
| Garmin | дорого, ЧБ-экран, неофициальный и нестабильный API |
| Amazfit | рассматривался как бюджет под пульс (Zepp2Hass, community-интеграция), но для давления не годится |

Ключевой критерий: **давление меряется манжетой**. Всё, что обещает
давление с запястья оптическим методом, для 85-летнего человека с
реальными рисками — не измерительный прибор.
