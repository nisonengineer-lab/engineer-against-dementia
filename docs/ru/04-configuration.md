# Настройка

Разбор `frigate/config.example.yaml`. Значения подобраны эмпирически;
дефолты Frigate заметно мягче и на этой установке давали ложные
срабатывания.

---

## Маски: сначала маска, потом всё остальное

Маска убирает из обработки области, где детекция не нужна: улица за
забором, соседский двор, крона дерева на ветру.

Это не оптимизация ресурсов, а условие работоспособности. Без маски
дворовая камера ловит прохожих с тротуара — и система будит человека
десять раз за ночь. На третью ночь её отключат.

Рисовать в UI: **Settings → Mask & Zone Editor**. Координаты
нормализованные (0–1), поэтому не зависят от разрешения.

## Зоны: разделять по смыслу, а не по геометрии

```yaml
zones:
  home:    # крыльцо — «человек вернулся»
  yard:    # двор — «вышел, но на территории», тревоги нет
  Exit:    # калитка — ЭТО тревога
```

Три зоны вместо одной, потому что у них разная логика реакции. «Вышел во
двор» и «вышел за калитку» — принципиально разные события для человека
с деменцией.

### `inertia`

Сколько кадров подряд объект должен быть в зоне, прежде чем зона
считается занятой.

| Значение | Где | Почему |
|---|---|---|
| `1` | зона тревоги (калитка) | человек проходит её за секунды; ждать нельзя |
| `3` | бытовые зоны (кухня, спальня) | гасит дёрганье на проход мимо |

### ⚠️ Регистр имён зон

В конфиге зона называется `Exit`. В шаблонах Home Assistant сравнение
регистрозависимое. Если не привести к нижнему регистру:

```jinja
{{ 'exit' in trigger.payload_json['after']['entered_zones'] | map('lower') | list }}
```

— триггер **не сработает, молча**, без ошибки в логах.

## Пороги детекции

```yaml
filters:
  person:
    min_score: 0.6      # ниже — детекция вообще не рассматривается
    threshold: 0.7      # порог, чтобы объект считался подтверждённым
    min_area: 500       # мельче — мусор
```

**Уличная камера мягче, комнатная строже** (`0.6` против `0.8`). В
помещении много ложных срабатываний на мебель, отражения и тени; на
улице важнее не пропустить человека вдалеке.

## Разделение detect / record

```yaml
inputs:
  - path: rtsp://...
    roles: [detect]
  - path: rtsp://...
    roles: [record]
```

Один и тот же URL, две роли. Детекции нужен низкий latency и она терпит
потерю качества; записи нужен полный битрейт и она терпит задержку. На
одном потоке требования конфликтуют.

---

## `stationary`

```yaml
stationary:
  threshold: 5
```

Через сколько кадров неподвижный объект перестаёт пересчитываться каждый
кадр. Экономит GPU, но здесь есть тонкость: **человек, лежащий
неподвижно, — это и есть целевое событие**. Слишком агрессивная
настройка «забудет» его. `5` — компромисс.

## Распознавание лиц

```yaml
face_recognition:
  detection_threshold: 0.75    # уверенность, что лицо вообще найдено
  recognition_threshold: 0.87  # уверенность в сопоставлении с известным
  unknown_score: 0.78          # ниже — «неизвестный»
  min_area: 2000               # мелкие лица не пытаться распознавать
  min_faces: 2                 # кадров подряд для присвоения имени
  blur_confidence_filter: true # штраф за смазанные кадры
```

Пороги выше дефолтных: со стандартными система путала членов семьи.

**Пороги — вторичны. Первична дисциплина обучающей базы.** 20–50
качественных фото на человека работают лучше, чем 500 случайных.
Подробнее — [06-ai-models.md](06-ai-models.md).

## Классификация по внешнему виду ⚠️

```yaml
classification:
  custom:
    person_by_appearance:
      object_config:
        classification_type: attribute   # ← не sub_label
```

Страховка на случай, когда лица не видно: силуэт, одежда.

**`attribute`, а не `sub_label`.** При типе `sub_label` результат
конфликтует с распознаванием лиц, которое пишет в то же поле.

**Статус экспериментальный.** После добавления этой секции Frigate
отдавал 502 на auth-сервисе. Не диагностировано. Ловишь 502 —
закомментируй блок и перезапусти контейнер.

## Хранение

```yaml
record:
  alerts:    { retain: { days: 7, mode: motion } }
  detections:{ retain: { days: 7, mode: motion } }
snapshots:
  retain:    { default: 14 }
```

Семь дней. Больше упирается и в диск, и в здравый смысл: разбирать
инцидент недельной давности всё равно никто не будет. Плюс это разумный
предел хранения видео с людьми в их собственном доме.

## Аппаратное ускорение

```yaml
ffmpeg:
  hwaccel_args: preset-nvidia
```

| Платформа | Значение |
|---|---|
| NVIDIA GPU | `preset-nvidia` |
| Raspberry Pi 5 | `preset-rpi-64-h264` |
| Intel iGPU | `preset-vaapi` |

Без аппаратного декодирования CPU уходит в потолок на двух камерах 4K.

## Секреты

В `config.yaml` не пишется ни один пароль:

```yaml
mqtt:
  password: "{FRIGATE_MQTT_PASSWORD}"
```

Frigate подставляет переменные окружения с префиксом `FRIGATE_` — но
**только в тех полях, где это разрешено** в reference config (`mqtt.*`,
`ffmpeg.inputs.path` и ещё несколько). Это не универсальный механизм
подстановки по всему файлу.

Значения — в `.env`, который в `.gitignore`.
