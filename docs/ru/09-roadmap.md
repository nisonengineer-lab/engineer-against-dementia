- [ ] `activity_watcher`: клип из Frigate → кадры → описание → в HA

## Долгосрочно: продукт

Не глобальный стартап. Малый локальный бизнес для русскоязычной общины в
Израиле: установка и поддержка систем ухода за пожилыми родственниками.

Ориентир: комплект ~2500–3500 ₪ разово + ~250–300 ₪/мес за поддержку.

Что должно быть готово до первого платящего клиента:

- [ ] Установка укладывается в один день по чеклисту
- [ ] Система переживает неделю без вмешательства — доказано, не предположено
- [ ] Ложные тревоги на уровне, при котором её не отключат на третью ночь
- [ ] Понятный родственнику интерфейс: что произошло, без чтения логов
- [ ] Внятная позиция по данным и согласию, на русском и на иврите
- [ ] Резервный канал оповещения на случай, когда упал интернет

Самый недооценённый пункт здесь — третий. Технически совершенная система,
которую отключили из-за ночных ложных срабатываний, спасает ноль человек.
