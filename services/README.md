# Сервисы

| Папка | Что это |
|---|---|
| [`care_monitor/`](care_monitor/) | Аддон Home Assistant **Care Monitor**. Слушает события Frigate по MQTT, режет клип на кадры и задаёт vision-модели (Ollama, `qwen3-vl`) короткие вопросы по одному: это он? упал? спит? поза? ест? туалет? походка? Ответы складывает в SQLite и шлёт уведомления. Хранит данные не дольше `retention_days`. |
| [`care_api/`](care_api/) | Аддон **Care Journal API**. Отдаёт журнал сайту: лента, фильтры, кадры, видео, оценка «верно / ложно», переоценка. Под `/demo/` — открытый демо-журнал на английском из отдельной базы. |
| [`care_demo/`](care_demo/) | Сборка демо: `build_demo.py` берёт отобранные события из копии данных, переводит карточки и пишет `demo.db` + ролики. `server.py` — локальная страница мониторинга данных. |
| [`vision/`](vision/) | Первые тесты vision-модели, с которых всё началось. |

Данных здесь нет: ни видео, ни баз, ни фото. Адреса домашней сети и пароли
заменены на `CHANGEME`, `MQTT_HOST`, `FRIGATE_HOST`, `OLLAMA_HOST_IP` —
настоящие значения задаются в настройках аддонов.
